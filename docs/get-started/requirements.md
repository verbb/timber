# Requirements

## Craft CMS
Timber requires Craft CMS 5.0 or greater.

## PHP
Timber requires PHP 8.2 or greater.

## Server
For Timber to use real-time log updates your server will need to support the `tail` command, and you must enable real-time updates in Settings (see [Real-Time Logs](docs:feature-tour/real-time-logs)). The Control Panel connects to the socket server on `localhost`.
